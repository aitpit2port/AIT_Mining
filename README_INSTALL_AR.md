# AIT GeoMine 360 — GitHub Pages V3.2

هذا المجلد هو الوحيد الذي يُرفع إلى مستودع GitHub.

قبل الرفع:
1. افتح `dashboard/backend-config.js`.
2. استبدل `PASTE_APPS_SCRIPT_EXEC_URL_HERE` برابط Web App المنتهي بـ `/exec`.
3. ارفع محتويات هذا المجلد إلى جذر Repository باسم `AIT-GeoMine-360`.
4. من Settings > Pages اختر GitHub Actions.

لا يحتوي هذا المجلد على قاعدة البيانات أو الخرائط أو ملفات PDF الأصلية. يتم تحميلها بعد تسجيل الدخول من Google Sheets وGoogle Drive عبر Apps Script.
